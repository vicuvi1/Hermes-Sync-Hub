# Hermes Hub v0.9.1

This release makes first-time Windows installation simpler.

## What changed

- The installer now uses the stable filename **`Hermes-Hub-Setup-x64.exe`**.
- The GitHub README has a prominent permanent link that always downloads the latest installer.
- Installation requires no Git, Node.js, terminal, or source checkout.
- The guided NSIS installer creates Desktop and Start Menu shortcuts and includes uninstall support.

## Install

Download and run **`Hermes-Hub-Setup-x64.exe`** from the assets below. Current public-beta builds are unsigned, so Windows SmartScreen may show a warning. Verify `SHA256SUMS.txt`, then choose **More info → Run anyway** if the publisher information and checksum are correct.
