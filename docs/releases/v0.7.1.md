# Hermes Hub v0.7.1

Smart Router now offers an optional fully local semantic classifier built on maintained open-source components. It improves intent recognition without adding Python, a routing server, hosted embeddings, or provider-credit usage.

## Highlights

- Choose between the bundled deterministic classifier and local semantic routing.
- Prepare a quantized MiniLM ONNX model with one explicit click; it is downloaded once and cached under Hermes Hub application data.
- Run embeddings locally with Apache-2.0 Transformers.js and ONNX Runtime.
- Configure the minimum semantic confidence required to override deterministic categorization.
- See semantic confidence in the routing explanation.
- Fall back automatically to deterministic routing when the model is missing, offline, fails to load, or produces a low-confidence match.
- Keep all paid-model approvals, complexity floors, confirmations, and budgets from v0.7.0.

## Cost and privacy

- Preparing the model uses approximately 24 MB of download bandwidth and local disk space.
- Classification makes no provider request and spends no model or API credits.
- Task text is embedded locally and is not sent to Hugging Face; only model files are downloaded during preparation.
- Hermes receives the task only after the normal execution confirmation.

## Install or update

1. Download **`Hermes-Hub-Setup-0.7.1-x64.exe`** below.
2. Compare its SHA-256 hash with **`SHA256SUMS.txt`**.
3. Run the installer. This public-beta release remains unsigned, so Windows SmartScreen may require **More info → Run anyway** after verification.
4. Existing packaged installations can update from **Settings → Application Update**.
