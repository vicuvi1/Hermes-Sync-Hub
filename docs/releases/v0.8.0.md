# Hermes Hub v0.8.0

This release turns Smart Router's OpenRouter support into a real Hermes-connected workflow rather than only a policy editor.

## Highlights

- Verify the OpenRouter key already used by Hermes without revealing it or making a model request.
- View redacted account tier, usage, limit, and remaining-budget metadata.
- Search the live OpenRouter catalog by model/provider and filter for free or tool-capable models.
- Import live catalog entries into the routing policy with current price and capability metadata.
- Apply a primary model and ordered fallback chain directly to any detected Hermes profile.
- Create an automatic recovery backup before profile configuration changes.
- Run a tiny, confirmed end-to-end request through the actual Hermes CLI and OpenRouter provider.
- Keep local deterministic and optional semantic task classification, paid-model allowlisting, and strict budgets from v0.7.

## Privacy and cost behavior

The OpenRouter API key is read only in the privileged Electron main process from the environment path reported by Hermes. It is never returned to React, logged, indexed, or stored in the routing policy. Connection verification uses OpenRouter's key-information endpoint and consumes no model credits. The live Hermes test is always confirmed; free models cost $0 but consume request quota, while paid models may incur a small charge.

## Install

1. Download **`Hermes-Hub-Setup-0.8.0-x64.exe`** from the release assets.
2. Run the installer. Windows SmartScreen may warn because the initial public beta is unsigned.
3. Open **Smart Router → OpenRouter live**.
4. If the key is missing, save it in **Shared Vault**, apply the environment to Hermes, and return to verify it.
5. Select a Hermes profile, primary model, and fallbacks; choose **Apply to Hermes**.
