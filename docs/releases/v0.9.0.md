# Hermes Hub v0.9.0

Hermes Hub now keeps supported Hermes data synchronized in the background instead of requiring repeated clicks on **Sync Now**.

## Highlights

- Continuous file watching with edit-burst debouncing.
- Automatic startup reconciliation and periodic safety retries.
- Fast, balanced, normal, and battery-saver intervals in Settings.
- Automatic retry when Syncthing or a peer is offline.
- Serialized background and manual cycles to prevent races.
- Correct authenticated Syncthing `POST` rescans.
- Automatic discovery of every configured Hermes-related Syncthing folder.
- Real transfer-rate measurement from Syncthing counters.
- Live status, last success, changed-action count, conflicts, and transport readiness in the UI.

## Safety model

The selected Main PC remains initial-baseline authority. After adoption, supported files stay bidirectional. Revision hashes, deletion tombstones, recovery artifacts, conflict copies, and live-database exclusions remain active. Continuous synchronization does not force an ambiguous version over another PC.

## Required transport setup

Continuous reconciliation works locally whenever Hermes Hub runs. Cross-PC transfer additionally requires Syncthing to be installed, running, paired, and configured with the same `HermesHubData` folder in **Send & Receive** mode on every PC. Tailscale is recommended for direct private connectivity. The Settings screen can install the official requirements, but account sign-in and device trust remain explicit user actions.

## Install

Download **`Hermes-Hub-Setup-0.9.0-x64.exe`** from the assets below. The initial public beta is unsigned, so Windows SmartScreen may display a warning.
