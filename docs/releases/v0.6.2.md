# Hermes Hub v0.6.2

Hermes Hub now has a real product gallery. Every screenshot was captured from the release UI—not reconstructed in a design tool—and uses sanitized Demo Mode content.

## Highlights

- Added high-resolution previews of the Overview, Sessions workspace, and encrypted Shared Vault to the GitHub project page.
- Added the same visual tour to the in-app **Help & README** handbook.
- Replaced developer-specific Demo Mode names, paths, hostnames, and network examples with neutral sample data.
- Added polished responsive image styling and descriptive alternative text.

The screenshots clearly retain the Demo Mode label where it is part of the visible interface. No personal sessions, real device identities, filesystem paths, credentials, or secret values were published.

## Install or update

1. Download **`Hermes-Hub-Setup-0.6.2-x64.exe`** below.
2. Compare its SHA-256 hash with **`SHA256SUMS.txt`**.
3. Run the installer. This public-beta release remains unsigned, so Windows SmartScreen may require **More info → Run anyway** after verification.
4. Existing packaged installations can update from **Settings → Application Update**.

## Included release artifacts

- Windows x64 NSIS installer
- In-app update metadata and blockmap
- SHA-256 checksums
- Dependency SBOM
