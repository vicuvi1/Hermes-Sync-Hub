# Hermes Hub v0.7.0

Hermes Hub now includes a Smart Model Router and native Hermes bot builder. It keeps Hermes as the agent runtime while adding a visual, explainable policy layer for choosing free or explicitly approved paid models.

## Highlights

- Create real isolated Hermes profiles from the UI and give each one a clear purpose, default model pool, and optional forced skills.
- Classify task complexity locally and route ordinary work to free models by default.
- Escalate difficult work only to paid models you explicitly enable and approve.
- Enforce a paid complexity floor, maximum cost per task, daily cost ceiling, and daily paid-run limit.
- Build ordered rules by task category and complexity range, and organize exact provider/model IDs into reusable pools.
- Refresh current OpenRouter model prices, context windows, and free/paid status from the live public catalog.
- Simulate the complete decision before running it, including the score, reasons, pool, model, and estimated cost.
- Run a confirmed task through the installed Hermes CLI and keep a redacted local routing audit trail.

## Trust boundaries

- The router does not replace Hermes or intercept prompts entered in another Hermes window.
- Every Hub-started model request requires user confirmation.
- Paid routing fails closed when approval, complexity, or budget checks fail.
- The renderer cannot run arbitrary shell commands; it can only use validated typed router operations.
- Vault values and provider keys are never stored in the routing policy or history.
- Failed tool-using tasks are not automatically retried, avoiding accidental duplicate side effects.

## Install or update

1. Download **`Hermes-Hub-Setup-0.7.0-x64.exe`** below.
2. Compare its SHA-256 hash with **`SHA256SUMS.txt`**.
3. Run the installer. This public-beta release remains unsigned, so Windows SmartScreen may require **More info → Run anyway** after verification.
4. Existing packaged installations can update from **Settings → Application Update**.
