# Hermes Hub v0.6.1

Hermes Hub is a local-first Windows companion for Hermes Agent. It brings health, memories, skills, MCP servers, plugins, credentials, synchronization, backups, usage, and safe updates into one visual control center—without replacing the Hermes application.

## What is new

This release makes the project easier to evaluate and adopt:

- A redesigned public README explains the problem Hermes Hub solves, its trust model, major workflows, current beta status, and a five-minute setup.
- The same detailed handbook is bundled inside **Help & README**, so installed guidance matches the release being used.
- New users get clearer download, checksum, SmartScreen, support, privacy, and multi-PC instructions.
- GitHub releases now use curated release notes when available, with generated notes as a fallback.

It includes the complete v0.6 Hermes Booster introduced in the previous release:

- Live Hermes Doctor health checks and redacted repair output.
- Skills, Skill Sync, MCP server, tool, and plugin inventory and controls.
- Usage, model, pricing, memory, credential, and workspace visibility.
- Backup-first Hermes updates using Hermes' official updater.
- A direct **Open Hermes App** action that keeps Hermes Hub firmly in its companion role.

## Install or update

1. Download **`Hermes-Hub-Setup-0.6.1-x64.exe`** below.
2. Compare its SHA-256 hash with **`SHA256SUMS.txt`**.
3. Run the installer. Windows SmartScreen may warn because this public-beta build is not yet code-signed; choose **More info → Run anyway** only after verifying the download and repository.
4. Existing packaged installations can also install this release from **Settings → Application Update**.

The installed application does not require Git, Node.js, pnpm, or a source checkout.

## Important beta notes

- Windows 10/11 x64 is the only supported production platform.
- Releases are currently unsigned.
- Tailscale and Syncthing remain external tools; Hermes Hub guides installation and configuration but does not create accounts or approve trust relationships.
- Multi-device synchronization is conservative by design. Keep verified backups for irreplaceable data and resolve ambiguous changes through the conflict workflow.
- Hermes update failures originating from the local Hermes Git checkout are reported honestly and are not treated as successful updates.
